# Pidgin Sentiment Engine

Web demo for a sentiment model fine-tuned on the NaijaSenti Nigerian Pidgin tweets.
Sentiment is predicted by the model; intent and moderation are keyword rules.

Source code, training notebook and evaluation: https://github.com/Ezechis/pidgin-sentiment
